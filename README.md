# Financial Fraud Detection Using Machine Learning

**Course:** INT234 — Predictive Analytics

## Project Overview
This project explores financial transaction fraud detection using machine learning. It includes data preprocessing, exploratory data analysis (EDA), visualisation, model training, and evaluation.

## Dataset
Source: Mendeley Data — Synthetic Mobile Money Transaction Dataset Version 2
https://data.mendeley.com/datasets/zhj366m53p/2

The dataset contains synthetic transactions, not actual Indian UPI or bank transactions.

## Notebook
Open `INT234_Financial_Fraud_Detection.ipynb` in Google Colab or Jupyter Notebook.

## Requirements
Install the main dependencies:

pip install pandas numpy matplotlib seaborn scikit-learn jupyter

Ensure the dataset is available at the file path specified in the notebook before running it.

## Limitations
Results depend on the synthetic dataset and its labelling patterns. They should not be interpreted as validated real-world fraud-detection performance.
